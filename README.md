# BatchCraft Update Bridge

พื้นที่นี้จัดทำขึ้นเพื่อให้ผู้ใช้ BatchCraft v1.3.3 และเวอร์ชันก่อนหน้าได้รับการแจ้งเตือนให้อัปเดตไปยังเวอร์ชันปัจจุบัน

This public repository is an update bridge for existing BatchCraft v1.3.3 users. It contains no application source code.

## ดาวน์โหลด / Download

ดาวน์โหลดเวอร์ชันล่าสุดจาก [BatchCraft Downloads](https://github.com/nikonboy2532-stack/BatchCraft-Downloads/releases/latest)

- ผู้ใช้ทั่วไป: เลือกไฟล์ Setup `.exe`
- Portable: เลือกไฟล์ `win-x64.zip`

โปรแกรมและเครื่องหมาย BatchCraft เป็นลิขสิทธิ์ของผู้พัฒนา ห้ามดัดแปลง ขายต่อ หรือแจกจ่ายใหม่จากแหล่งดาวน์โหลดที่ไม่เป็นทางการ
